# source-grounded-content-writing（证据驱动内容写作）

把论文、报告、新闻、书籍、访谈或用户提供的素材，转写成有事实依据、有个人语气的中文内容。适合公众号文章、博客、说明性随笔、反思评论等创作场景。

## 它解决什么问题

- **忠于来源**：以提供的素材为事实边界，不夸大、不编造，区分「事实 / 解释 / 延伸 / 待核实」。
- **结论严谨**：结论强弱必须匹配来源——来源明确才写明确结论；来源说「尚未证实 / 尚无定论 / 有争议」，正文就原样保留不确定，不升格成事实。
- **读得下去**：介绍与举例段落只负责「引出」，不负责「陈列」；例子自然带出、接回结论，不做生硬罗列。
- **可追溯**：每次创作同时产出「可发布稿」和「事实底稿」，事实、解释、延伸、待核实一目了然。

## 使用方式

在创作请求中引用本 skill，并提供素材（论文 / 报告 / 新闻 / 链接 / 文本）。完成后会生成两个文件：

1. `<slug>-publish.md`：可直接发布的成稿
2. `<slug>-fact-brief.md`：内部事实底稿（创作定位、来源登记、事实台账、结构、表述边界、可衍生内容）

## 工作流程

1. **登记来源**：建立来源台账，逐条归类 事实 / 解释 / 延伸 / 待核实，并标注来源结论状态（明确结论 / 部分证实 / 尚无定论）。
2. **找到文章真正的问题**：一句话说出核心张力，优先选「人」的问题而非技术标题。
3. **搭提纲（每段一个职责）**：介绍与例子段落在提纲里就要回答「它引出什么」。
4. **起草**：事实绑定来源；介绍要「引出」不要「陈列」；结论强弱匹配来源。
5. **三遍编辑**：结构 → 冗余 → 语气（清除公式化连接词）。
6. **终审**：逐句核对事实；单独检查「有没有把未证实内容当事实」「有没有一段介绍只是陈列素材」。
