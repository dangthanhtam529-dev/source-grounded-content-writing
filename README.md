# source-grounded-content-writing（证据驱动内容写作）

一个把外部素材转写成中文内容的写作 skill：以素材为事实边界，保留个人语气，同时保证结论严谨、可读性好。适用于公众号文章、博客、说明性随笔、反思评论、内容再创作等场景。

## 这个 skill 解决什么问题

写作类 AI 的产出，常见的三个毛病：

1. **编造与夸大**：脱离素材自由发挥，把"可能"写成"一定"。
2. **结论不严谨**：来源明明标注"尚未证实 / 尚无定论 / 存在争议"，正文却当成事实直接下结论。
3. **可读性差**：介绍和举例段落像在"陈列素材"，生硬堆砌，读者在进入正题之前就被劝退。

本 skill 通过"来源台账 + 结论分级 + 引出式写作"三条纪律来约束这些问题，让产出既可靠，又读得下去。

## 核心设计原则

| 原则 | 含义 |
|---|---|
| 忠于来源 | 素材是事实边界；每一条陈述内部归类为 事实 / 解释 / 延伸 / 待核实 |
| 结论分级 | 结论强弱必须匹配来源的确定程度；未证实内容不得升格为事实 |
| 引出式写作 | 介绍与举例段落只负责"引出"，不负责"陈列"；每段都有明确职责 |
| 双文件交付 | 每次创作产出 可发布稿 + 事实底稿，可追溯、可复核 |

## 使用方式

在创作请求中引用本 skill，并提供素材（论文 / 报告 / 新闻链接 / 访谈记录 / 文本均可）。默认输出中文，需要其他语言请显式说明。

- 用户未要求直接成稿时：先给出核心命题与提纲，确认后再起草；
- 用户要求直接成稿时：内部完成提纲，直接产出两份文件。

产出文件默认写入当前工作区（或用户指定目录）：

1. `<slug>-publish.md`：可发布成稿，只包含面向读者的内容（标题、正文、可选的资料来源注记）。
2. `<slug>-fact-brief.md`：内部事实底稿，不对外发布（结构见下文）。

## 工作流程（六步）

1. **登记来源**：通读素材，建立来源台账（标题/日期/位置/可用断言）；逐条归类 事实 / 解释 / 延伸 / 待核实；对可能形成结论的事实，标注来源结论状态：明确结论 / 部分证实 / 尚无定论。
2. **找到文章真正的问题**：一句话写出核心张力；优先选"人的问题"而非技术标题；区分"素材研究了什么"与"文章想讨论什么"。
3. **搭提纲（每段一个职责）**：每段标注职责（场景 / 问题 / 概念 / 方法 / 证据 / 解读 / 延伸 / 结尾）与依据；介绍与举例段必须在提纲里回答"它引出什么"，答不上来就从提纲删除。
4. **起草**：事实绑定来源、精确归因（"该调查显示"，而非"研究证明"）；介绍要"引出"不要"陈列"；结论强弱匹配来源；语气贴合题材——个人化、冷静好奇、轻松克制，不冰冷也不煽情。
5. **三遍编辑**：结构（段段推进、有桥接）→ 冗余（一个核心论点只完整讲一遍）→ 语气（清除公式化连接词与排比口号）。
6. **终审**：逐句核对数字、范围、方法、因果；再单列两遍检查——有没有把未证实内容当事实下结论、有没有一段介绍或例子只是在陈列素材。

## 写作约束摘要（重点）

### 介绍与举例：要"引出"，不要"陈列"

- 先给读者一个具体的场景、疑问或反差，再自然过渡到正题；不要先堆背景信息。
- 例子只选最能支撑当前论点的那一个，写进叙述里；不用"举个例子：A。再比如：B。"式罗列，也不为"显得丰富"硬塞多个例子。
- 例子写完后，至少用半句话接到它要说明的结论上；接不上，说明这个例子没在干活。
- 避免生硬连接词：值得一提、举个例子来说、事实上、不难发现、众所周知、首先/其次/最后。
- 自查标准：删掉这段后，后面的表达与结论依然成立且无损 → 它在"陈列"，重写或删除。

### 结论：强弱必须匹配来源

- 来源明确，才用明确语气；来源含糊、未证实或有争议，就用限定语气（"据…报道""目前尚无定论""论文没有直接回答"）。
- 每条强结论都要能回指到来源的具体句子；回指不上，就降级为明确标注的"我的解读"，或删掉。
- 待核实内容只能作为明确标注的上下文或疑问出现，不能充当结论的前提。

## 交付物：事实底稿结构

事实底稿是内部文件，不对外发布，包含六个部分：

1. **创作定位**：题材、核心问题、中心命题、读者、语气
2. **来源登记**：来源、类型/日期、已阅读范围、用途
3. **事实台账**：编号、可用事实、来源定位、类型（事实 / 解释 / 延伸 / 待核实）、写作使用位置，并标注来源结论状态
4. **文章结构**：部分、段落职责、新信息、依据
5. **表述边界与限制**：不可写成的结论、研究或来源限制、尚待核实
6. **可衍生内容**：标题备选、可拆出的短内容或配图主题
